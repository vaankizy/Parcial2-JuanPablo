# SaberPro Microservices System (Refactored)

Sistema de microservicios para la gestión del ciclo de vida de preguntas SaberPro refactorizado y optimizado.

## Estructura de paquetes
- `co.edu.unicauca.saberpro.question` (Servicio de Preguntas)
- `co.edu.unicauca.saberpro.lifecycle` (Servicio de Ciclo de Vida)
- `co.edu.unicauca.saberpro.validation` (Servicio de Validación)

## Requisitos
- Java 17
- Maven 3.8+
- RabbitMQ / Docker
